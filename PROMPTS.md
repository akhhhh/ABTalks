# ABTalks — AI Usage Log

This project was developed with AI-assisted coding and design support.

## Project Planning

### Prompt 1
Designed a mobile-first ABTalks 60-day coding challenge platform for Indian college students. Create three screens: landing page, student dashboard, and challenge day page. Include streaks, progress, daily tasks, GitHub proof, LinkedIn proof, and submission flow.

### Prompt 2
Create a React frontend with proper component-based structure for the ABTalks hackathon project. Make it responsive, especially for a 390px mobile viewport.

### Prompt 3
Create a FastAPI backend for ABTalks with MongoDB Atlas for storing student data, challenge days, and submissions. Organize the backend into separate routers, services, database, models, and configuration files.

## Debugging

### Prompt 4
Debug FastAPI and MongoDB Atlas authentication errors and configure the MongoDB connection using environment variables.

### Prompt 5
Fix CORS issues between the React Vite frontend and FastAPI backend.

### Prompt 6
Fix React rendering errors caused by API data being unavailable during the initial render, including `.map()` errors on undefined requirements.

### Prompt 7
Configure the project for deployment with Vercel for the React frontend and Render for the FastAPI backend.

### Prompt 8
Configure Vercel environment variables and React Router rewrites for `/`, `/dashboard`, and `/day/12`.

## Deployment

### Prompt 9
Deploy the FastAPI backend to Render using Python, Uvicorn, requirements.txt, and MongoDB Atlas.

### Prompt 10
Deploy the React/Vite frontend to Vercel from the frontend directory and connect it to the deployed FastAPI backend.
